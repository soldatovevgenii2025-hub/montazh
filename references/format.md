# Рисованный ведущий

В бесплатной версии герой готовый: выбери одного из трёх в `heroes/hero-1`, `heroes/hero-2`, `heroes/hero-3`. У каждого есть лист персонажа `sheet.png` и четыре позы: `explains` (объясняет), `point` (показывает на зрителя), `relax` (отдыхает), `joy` (радуется); у каждой позы три рта: `rest`, `aa`, `oo`. Ноги во всех позах стоят в одной точке кадра, смысл позы записан в поле `about` манифеста. Профиль читает манифест героя сам: выбери героя в поле `hero`. Нельзя подставлять чужого героя. Герой по фото автора входит в платную версию.

Образец задаёт композицию, положение/масштаб ведущего, ритм и функции жестов. Зафиксируй карту: открытие, ожидание зрителя, проблема, действие, демонстрация, результат, призыв, последний кадр. Палитра и конкретный персонаж остаются собственными. Не переводь ведущего в центр по таймеру, если выбранная композиция этого не требует.

У готового героя уже есть библиотека целых выразительных поз с разными руками, плечами, взглядом и эмоцией; требования к ней такие. Для каждой позы нужны собственные rest/aa/oo состояния и, желательно, blink; они должны иметь одинаковый размер и общий якорь глаз. Общий bbox изменяется из-за рук — привязывай по глазам, а не по силуэту.

Публичный renderer использует полные согласованные состояния поз, поэтому исходный нарисованный рот не остаётся под наклейкой нового. Альтернативный mouth patch допустим только с проверенной нейтральной подложкой и собственной маской каждой позы. Сначала проверь каждую используемую позу в rest/aa/oo, затем реальные речевые кадры. Рот закрыт в паузах; активность берётся из точного RMS/слов. Это ограниченная артикуляция по словам/энергии, не обещание фонемного липсинка.

В profile.presenter: poses[{name,rest,aa,oo,blink,eyes:[x,y],width,height}], eyeAnchor:[x,y], scale. Все пути — свои файлы от корня проекта. В plan.pose_events: [{at,pose,reason}], начиная с нуля. Жест привязывается к смысловому слову/действию, не к случайному интервалу. Разные сцены развиваются движением предметов, контактом и результатом; неподвижный PNG с качанием и ртом не проходит приёмку.

У Instagram герой остаётся от первого до последнего кадра, включая CTA. Новая реплика или язык требует новой звуковой шкалы; визуальная правка сохраняет прежние проверенные аудиобайты. Проверяющий сравнивает actual MP4 с донором и собственным утверждённым листом: композицию, живость, смены силуэта, якорь головы, рот, руки, обрезания и результат демонстраций. Число поз само по себе не доказывает выразительность.
