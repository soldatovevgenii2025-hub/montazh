# Что изменено относительно creator-cartoon 1.1.0

Исходник: навык creator-cartoon 1.1.0, лицензия MIT («Copyright (c) 2026 Video Skill Contributors»). Эта сборка называется МОНТАЖ. Исходная строка копирайта и текст MIT сохранены, строка об изменениях добавлена отдельно.

## Изменения и дополнения

- Новое имя и slug: `montazh` (указатель проекта `~/.local/share/video-skills/montazh.json`), версия 0.1.0.
- Редакции `free` и `pro`: поле `edition` в `PACKAGE.json`, сборщик `build.py`. В free нет цикла, стилей, второго языка и аватара. Код этих функций в репозитории остался.
- Живой голос: режим `live` в профиле, `tools/live_voice.py` (подготовка записи, расшифровка в черновик), нестрогий `voice-qa` с выравниванием слов и списком расхождений.
- Три готовых героя вместо создания героя по фото (`heroes/`): Банан, Котёнок, Робот, у каждого 4 позы × 3 рта (PNG с прозрачным фоном). Герой по фото только в pro.
- Убран прежний сервис трендов, его справочник и ключ; в местах поиска трендов заглушка про источник на ступени 2.
- Приветствие, установка, подсказки и сообщения об ошибках на русском. Команды установки для macOS, Linux и WSL.
- Настройки: `config/providers.json` (генератор картинок, провайдер не выбран), `tools/image_gen.py` (сухой адаптер), `config/partners.json` (партнёрские ссылки).
- Учёт картинок отделён от учёта речи: у записи поле `kind: "media"`, имя провайдера берётся из настройки; старые записи `external-media` читаются.
- Установка в Claude Code и Codex, в личный проект кладутся `AGENTS.md` и `CLAUDE.md` с одинаковым текстом.
- Модели распознавания: small по умолчанию, medium по желанию (`setup_runtime.py --whisper medium`). Зависимости английского движка (`kokoro-onnx`, `espeakng-loader`, `onnxruntime`, `soundfile`) вынесены в `requirements-pro.txt`.
- Лимит ролика 60 секунд в free.
- `workspace/engine/remotion/Root.tsx`: правка от 10.11.2026 (необязательная артикуляция по `plan.mouth`, мост субтитров `plan.captionBridge`), без этих полей плана поведение исходное. Оригинала для сравнения нет.

## 0.1.1 (21.11.2026): исправления после установки «как покупатель»

- `live_voice.py transcribe` без `--platforms` больше не падает после расшифровки: площадки берутся из профиля (`profile.local.json`, затем `profile.draft.json`), без профиля ставится instagram.
- Русский текст в выводе инструментов печатается буквами, а не кодами `\u0421…`.
- Готовый стиль по умолчанию «ночь» (фон #1F2A44, акцент #FFD23F, белый текст) и два набора на выбор: «мята» и «слива» (`config/style-presets.json`, `style.preset`). Шрифт Montserrat ExtraBold лежит в `fonts/`, лицензия SIL OFL 1.1.
- `voice-qa` для живой записи сравнивает слова нечётко: латиница и кириллица («Claude Code» и «клод код»), окончания, двойные буквы. Порог 85% не менялся.
- `prepare` оставляет в начале не больше 0,04 с тишины (было 0,1 с).
- Субтитры не склеивают реплики через паузу и через конец фразы, сохраняют пунктуацию. По умолчанию стоят в нижней трети над героем, нижний край не ниже 78% кадра. Герои немного уменьшены и подняты (190–1270 px по высоте).
- Справка `install.py` по-русски, клиенты только claude и codex. Остатки `creator-cartoon-*` переименованы в `montazh-*`. Поддерживаемый Python: 3.11–3.13.
- Архив собирается побайтно одинаково (без времени в заголовке gzip).
