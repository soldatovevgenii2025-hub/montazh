# МОНТАЖ

Бесплатный скилл для Claude Code и Codex: мультик с готовым героем из твоего голосового.
Наговариваешь мысль, выбираешь героя (Банан, Котёнок или Робот) и получаешь вертикальный
ролик 1080x1920 с субтитрами. Голос твой собственный, ElevenLabs и ключи не нужны. Всё по-русски.

## Установка одной фразой

Открой на компьютере Claude Code или Codex и напиши:

```
Установи скилл МОНТАЖ из https://github.com/soldatovevgenii2025-hub/montazh по INSTALL.md
```

Фраза одна и та же для Claude Code и для Codex. Агент сам скачает скилл, проверит компьютер,
задаст пару вопросов и проведёт до первого мультика.

**Запасной путь.** Скачай архив `montazh-free-0.1.1.tar.gz` со страницы
[релиза](https://github.com/soldatovevgenii2025-hub/montazh/releases/latest) и напиши агенту:
«Найди у меня файл montazh-free-0.1.1.tar.gz и установи скилл по INSTALL.md».

## Что нужно

- macOS или Linux. Windows: через WSL2 (Ubuntu).
- Python 3.11, 3.12 или 3.13 (на 3.14 пока не работает).
- Node.js 20 или новее, FFmpeg.
- Около 5 ГБ свободного места: окружение, движок видео и модель распознавания речи.

Недостающее агент подскажет сам, с командой установки под твою систему.

## Для агента

Установка из репозитория: склонируй его во временную папку
(`git clone --depth 1 https://github.com/soldatovevgenii2025-hub/montazh.git ПАПКА`).
Это то же, что распакованный архив из шага 2 в [INSTALL.md](INSTALL.md): дальше иди с шага 3.
Установка из файла: с шага 1.
