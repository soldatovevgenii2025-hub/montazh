# Установка агентом

Устанавливай для текущего клиента: Claude Code или Codex. Не создавай каталоги другого клиента. Проект с личными настройками и медиа хранится отдельно от установленного навыка. Все сообщения автору пиши по-русски, коротко.

1. Проверь архив: `file montazh-free-0.1.1.tar.gz` должен показать gzip, `tar tzf` должен перечислить файлы с одной корневой папкой `montazh/`. HTML или JSON вместо архива не распаковывай: скажи автору, что скачивание не удалось, и попроси ссылку заново. Имена внутри должны быть относительными, без `..`, абсолютных путей и ссылок.
2. Распакуй во временную папку: `tar -xzf montazh-free-0.1.1.tar.gz -C TEMP --strip-components=1`.
3. Прочитай `PACKAGE.json`, `SKILL.md`, `AUTOPILOT.md`. Спроси только недостающее: какой клиент (Claude Code или Codex) и где создать личный проект. Предложи `~/montazh-project`. Существующую папку с чужими файлами не занимай.
4. Нужен Python 3.11, 3.12 или 3.13. На 3.14 окружение не соберётся: для закреплённых зависимостей нет готовых пакетов. Узнай версию: `python3 --version`. Если там 3.14 или ниже 3.11, поставь 3.13 (см. «Если что-то пошло не так») и дальше вместо `python3` пиши `python3.13`. Запусти из распакованной папки: `python3 install.py --client claude --project PATH`. Для Codex: `--client codex`. Навык встанет в `~/.claude/skills/montazh` или `~/.agents/skills/montazh`. Старую копию установщик сохраняет как резервную, существующий личный проект не перезаписывает. Указатель проекта: `~/.local/share/video-skills/montazh.json`.
5. Проверка окружения, ничего не ставит: из проекта `python3 tools/setup_runtime.py --check`. Покажи автору, что есть и чего нет, с командой установки для его системы. Нужны Python 3.11–3.13, Node.js 20+, FFmpeg и FFprobe. Код использует `fcntl`: macOS и Linux работают, на Windows запускай проект в WSL2 (Ubuntu), не в Windows Python.
6. Когда всё есть: `python3 tools/setup_runtime.py --models`. Создаётся отдельное окружение, ставятся закреплённые зависимости, Remotion и Chromium, скачивается модель распознавания речи с проверкой SHA256. Нужно несколько гигабайт и время. Ключи и платные вызовы здесь не используются. Нельзя подменять недостающую модель случайной. Модель точнее (`--whisper medium`, около 1,5 ГБ) ставь только если распознавание живой речи плохое.
7. Прочитай `THIRD_PARTY.md` и скажи автору главное: у Remotion своя лицензия. Бесплатно для частных лиц и компаний до трёх человек, иначе нужна своя лицензия: https://www.remotion.dev/license . Установщик ничего не покупает.
8. Открой `AUTOPILOT.md` и веди автора по блокам. Личные фото, записи голоса и токены остаются в личном проекте и в окружении. Никогда не клади реальные ключи в установку навыка.
9. Проверь вызов: агент по фразе из `description` должен прочитать навык `montazh`, найти личный проект и назвать следующий реальный шаг. Установка не включает публикацию и платные вызовы.

## Если что-то пошло не так

- **Python не 3.11–3.13** (например, 3.14). macOS: `brew install python@3.13`, затем запускай установку и проверку командой `python3.13` вместо `python3`. Linux или WSL: `sudo apt install python3.13 python3.13-venv` (если в системе нет 3.13, подойдёт `python3.12 python3.12-venv`). После `setup_runtime.py` все инструменты запускаются из окружения проекта: `runtime/venv/bin/python tools/...`, там версия уже правильная.
- **Нет Node.js 20+.** macOS: `brew install node@20`. Linux или WSL: поставь Node.js 20 или новее штатным способом.
- **Нет FFmpeg.** macOS: `brew install ffmpeg`. Linux или WSL: `sudo apt install ffmpeg`.
- **Windows.** Поставь WSL2 с Ubuntu и запусти всё там. В обычном Windows Python проект не работает.
- **Скачивание модели оборвалось или не сошёлся SHA256.** Запусти `setup_runtime.py --models` ещё раз: готовые файлы не качаются заново. Если снова не сошлось, остановись и скажи автору, не подменяй модель.
- **Мало места.** Освободи от 5 ГБ и повтори шаг 6.
- **Папка проекта не пуста.** Выбери новую папку: установщик чужие файлы не трогает.

Обновление: сделай резервную копию личного проекта и его профиля; сравни новую версию движка, сохрани медиа, журналы и квитанции. Не копируй поверх проекта весь новый шаблон. Готовые выпуски продолжаются по своим снимкам и SHA.
